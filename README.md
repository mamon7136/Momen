# مومن — منصة SaaS سودانية لبناء المتاجر الإلكترونية

منصة متعددة المستأجرين (Multi-tenant) لبناء المتاجر الإلكترونية، فكرتها مشابهة لسلة وزد، ومصممة للسوق السوداني:
**بنكك (mBoK)** و**الدفع عند الاستلام بعربون** و**إشعارات واتساب** و**الشحن حسب الولاية والمدينة والحي** وواجهات **PWA خفيفة** تعمل على الإنترنت الضعيف.

| الوثيقة | المحتوى |
|---|---|
| [docs/01-PRD-ARCHITECTURE.md](docs/01-PRD-ARCHITECTURE.md) | المتطلبات، المكدس التقني، قاعدة البيانات، خارطة الطريق، تصميم الدفع والشحن، المخاطر |
| [docs/02-DEPLOY-DIRECTADMIN.md](docs/02-DEPLOY-DIRECTADMIN.md) | النشر خطوة بخطوة على استضافة DirectAdmin + Wildcard + الدومينات الخاصة + واتساب |

## المزايا المبنية
- **التاجر**: تسجيل واختيار الباقة والثيم والرابط، منتجات (بسيطة، بخيارات، رقمية)، مخزون لكل فرع، طلبات بحالات كاملة، تأكيد إيصالات بنكك بنقرة، بوليصات شحن وفواتير للطباعة، كوبونات، سلات متروكة، تقارير أرباح، محفظة وسحب، موظفين بخمسة أدوار، منشئ صفحات بلا كود، دومين خاص، متجر تطبيقات.
- **العميل**: متجر عربي Mobile-first، دفع بخطوة واحدة مع حساب الشحن والخصم لحظياً، تتبع الطلب، رفع إيصال الدفع، زر واتساب، PWA قابل للتثبيت ويعمل Offline.
- **مدير المنصة**: المتاجر، تفعيل الاشتراكات من الإيصالات، الباقات والعمولات، الثيمات، طلبات السحب، أسعار الصرف، شركات الشحن العامة.

## التشغيل محلياً
```bash
composer install
cp .env.example .env && php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan storage:link
php artisan serve
```
| الرابط | الحساب |
|---|---|
| http://localhost:8000 | الصفحة الرئيسية للمنصة |
| http://localhost:8000/s/demo | المتجر التجريبي "متجر النيل" (كوبون `WELCOME10`) |
| http://localhost:8000/login | التاجر: `merchant@demo.sd` / `password` |
| http://localhost:8000/admin | المدير: `admin@platform.sd` / `ChangeMe!2026` |

رسائل واتساب وSMS تُكتب في `storage/logs/laravel.log` حتى تضبط `WHATSAPP_DRIVER=cloud`.
لتشغيل الطوابير محلياً: `php artisan queue:work`.
